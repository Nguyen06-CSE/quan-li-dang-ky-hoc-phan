# HƯỚNG DẪN CÀI ĐẶT CƠ SỞ DỮ LIỆU POSTGRESQL LOCAL

Tài liệu hướng dẫn thiết lập cơ sở dữ liệu PostgreSQL cục bộ cho hệ thống **Quản Lý Đăng Ký Học Phần (QuanLyDKHP)**, áp dụng đúng cấu trúc schema và sử dụng cơ chế Seed Data có sẵn trong dự án.

---

## 1. Yêu cầu tiên quyết
- **PostgreSQL**: Phiên bản 14 trở lên (khuyến nghị 15 hoặc 16).
- **.NET 8.0 SDK**: Đã cài đặt trên máy.
- **Công cụ dòng lệnh**: `dotnet-ef` CLI tool (nếu chưa cài, mở terminal chạy: `dotnet tool install --global dotnet-ef`).
- Quản lý DB (tùy chọn): pgAdmin 4, DBeaver hoặc dòng lệnh `psql`.

---

## 2. Tạo Cơ Sở Dữ Liệu PostgreSQL

### Cách 1: Sử dụng Docker (Khuyến nghị - Nhanh & Gọn)
Mở terminal/cmd và chạy lệnh sau để khởi tạo container PostgreSQL:

```bash
docker run --name postgres-local \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=quanlydkhp \
  -p 5432:5432 \
  -d postgres:16-alpine
```

### Cách 2: Cài đặt trực tiếp trên máy (Native PostgreSQL)
1. Mở tiện ích `psql` từ Terminal / Command Prompt:
   ```bash
   psql -U postgres
   ```
2. Nhập mật khẩu tài khoản `postgres`, sau đó tạo database:
   ```sql
   CREATE DATABASE quanlydkhp;
   \c quanlydkhp
   ```

---

## 3. Khởi Tạo Schema Cho Database

Nếu bạn muốn tạo cấu trúc bảng thủ công qua SQL (hoặc khi không sử dụng lệnh EF Migration), hãy kết nối vào cơ sở dữ liệu `quanlydkhp` và thực thi script SQL sau:

```sql
-- 0. Kích hoạt tiện ích mở rộng tạo UUID
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

CREATE SCHEMA IF NOT EXISTS "public";

-- 1. Bảng lưu vết Migration EF Core
CREATE TABLE IF NOT EXISTS "__EFMigrationsHistory" (
	"MigrationId" varchar(150),
	"ProductVersion" varchar(32) NOT NULL,
	CONSTRAINT "PK___EFMigrationsHistory" PRIMARY KEY("MigrationId")
);

-- 2. Bảng Cấu hình hệ thống
CREATE TABLE IF NOT EXISTS "CauHinhHeThong" (
	"Key" varchar(50),
	"Value" varchar(50) NOT NULL,
	"MoTa" varchar(200),
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	CONSTRAINT "PK_CauHinhHeThong" PRIMARY KEY("Key")
);

-- 3. Bảng Sinh viên
CREATE TABLE IF NOT EXISTS "SinhVien" (
	"MaSV" varchar(20),
	"HoTen" varchar(100) NOT NULL,
	"LopSinhHoat" varchar(30),
	"KhoaHoc" varchar(20),
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	"IsDeleted" boolean DEFAULT false NOT NULL,
	CONSTRAINT "PK_SinhVien" PRIMARY KEY("MaSV")
);

-- 4. Bảng Môn học
CREATE TABLE IF NOT EXISTS "MonHoc" (
	"MaMon" varchar(20),
	"TenMon" varchar(150) NOT NULL,
	"SoTinChiLT" integer DEFAULT 0 NOT NULL,
	"SoTinChiTH" integer DEFAULT 0 NOT NULL,
	"BacDaoTao" varchar(10),
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	"IsDeleted" boolean DEFAULT false NOT NULL,
	CONSTRAINT "PK_MonHoc" PRIMARY KEY("MaMon"),
	CONSTRAINT "CK_MonHoc_SoTinChi" CHECK ((("SoTinChiLT" + "SoTinChiTH") > 0))
);

-- 5. Bảng Học kỳ
CREATE TABLE IF NOT EXISTS "HocKy" (
	"MaHocKy" varchar(20),
	"TenHocKy" varchar(50) NOT NULL,
	"NgayBatDau" date,
	"NgayKetThuc" date,
	"DangMo" boolean DEFAULT true NOT NULL,
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	CONSTRAINT "PK_HocKy" PRIMARY KEY("MaHocKy")
);

-- 6. Bảng Người dùng
CREATE TABLE IF NOT EXISTS "NguoiDung" (
	"Id" integer GENERATED BY DEFAULT AS IDENTITY (INCREMENT BY 1 MINVALUE 1 MAXVALUE 2147483647 START WITH 1 CACHE 1),
	"TenDangNhap" varchar(50) NOT NULL,
	"MatKhauHash" varchar(255) NOT NULL,
	"HoTen" varchar(100) NOT NULL,
	"Role" varchar(30) NOT NULL,
	"MaGV" varchar(20),
	"TrangThai" varchar(20) DEFAULT 'HoatDong' NOT NULL,
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	"IsDeleted" boolean DEFAULT false NOT NULL,
	CONSTRAINT "PK_NguoiDung" PRIMARY KEY("Id")
);
CREATE UNIQUE INDEX IF NOT EXISTS "IX_NguoiDung_TenDangNhap" ON "NguoiDung" ("TenDangNhap");

-- 7. Bảng Lớp học phần
CREATE TABLE IF NOT EXISTS "LopHocPhan" (
	"MaLHP" varchar(30),
	"MaMon" varchar(20) NOT NULL,
	"MaHocKy" varchar(20) NOT NULL,
	"MaGV" varchar(20),
	"LoaiHinhDT" varchar(10),
	"SiSoToiDa" integer,
	"GiangDayOnline" boolean DEFAULT false NOT NULL,
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	"IsDeleted" boolean DEFAULT false NOT NULL,
	CONSTRAINT "PK_LopHocPhan" PRIMARY KEY("MaLHP"),
	CONSTRAINT "FK_LopHocPhan_HocKy_MaHocKy" FOREIGN KEY ("MaHocKy") REFERENCES "HocKy"("MaHocKy") ON DELETE RESTRICT,
	CONSTRAINT "FK_LopHocPhan_MonHoc_MaMon" FOREIGN KEY ("MaMon") REFERENCES "MonHoc"("MaMon") ON DELETE RESTRICT
);
CREATE INDEX IF NOT EXISTS "IX_LopHocPhan_MaHocKy" ON "LopHocPhan" ("MaHocKy");
CREATE INDEX IF NOT EXISTS "IX_LopHocPhan_MaMon_MaHocKy" ON "LopHocPhan" ("MaMon", "MaHocKy");

-- 8. Bảng Đăng ký học phần
CREATE TABLE IF NOT EXISTS "DangKyHocPhan" (
	"Id" uuid DEFAULT gen_random_uuid(),
	"MaSV" varchar(20) NOT NULL,
	"MaLHP" varchar(30) NOT NULL,
	"HinhThucDK" varchar(10),
	"NgayDK" timestamp with time zone NOT NULL,
	"NguoiDK" varchar(50),
	"DiemSo" numeric(4, 2),
	"DiemChu" varchar(5),
	"TrangThai" varchar(20) DEFAULT 'DangHoc' NOT NULL,
	"SoTienPhaiDong" numeric(12, 2),
	"SoTienDaDong" numeric(12, 2) DEFAULT 0.0 NOT NULL,
	"NgayTao" timestamp with time zone DEFAULT now() NOT NULL,
	"NgayCapNhat" timestamp with time zone,
	CONSTRAINT "PK_DangKyHocPhan" PRIMARY KEY("Id"),
	CONSTRAINT "FK_DangKyHocPhan_LopHocPhan_MaLHP" FOREIGN KEY ("MaLHP") REFERENCES "LopHocPhan"("MaLHP") ON DELETE RESTRICT,
	CONSTRAINT "FK_DangKyHocPhan_SinhVien_MaSV" FOREIGN KEY ("MaSV") REFERENCES "SinhVien"("MaSV") ON DELETE RESTRICT
);
CREATE INDEX IF NOT EXISTS "IX_DangKyHocPhan_MaLHP" ON "DangKyHocPhan" ("MaLHP");
CREATE UNIQUE INDEX IF NOT EXISTS "IX_DangKyHocPhan_MaSV_MaLHP" ON "DangKyHocPhan" ("MaSV", "MaLHP");
```

## 4. Cấu Hình Chuỗi Kết Nối Ứng Dụng

Chỉnh sửa file cấu hình cục bộ `src/QuanLyDKHP.App/appsettings.Local.json` (hoặc tạo mới nếu chưa có):

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=quanlydkhp;Username=postgres;Password=postgres;SSL Mode=Disable;Trust Server Certificate=true"
  }
}
```

> **Lưu ý**: Thay đổi `Username` và `Password` khớp với tài khoản PostgreSQL local trên máy bạn.

## 5. Chạy Migration & Tự Động Kích Hoạt Seed Data

Dự án đã tích hợp sẵn cơ chế EF Core Migrations và Seeding dữ liệu mẫu (Tài khoản Admin, cấu hình đơn giá tín chỉ, môn học, lớp học phần mẫu,...).

Từ thư mục gốc của repository, mở Terminal/PowerShell và thực hiện:

### Bước 1: Áp dụng Migration & Chạy Seed
```powershell
dotnet ef database update --project src/QuanLyDKHP.Infrastructure --startup-project src/QuanLyDKHP.App
```

Lệnh trên sẽ:
1. Đồng bộ cấu trúc bảng vào DB `quanlydkhp`.
2. Tự động nạp toàn bộ Seed Data đã được định nghĩa trong `QuanLyDKHP.Infrastructure`.

### Bước 2: Chạy ứng dụng kiểm tra
```powershell
cd src/QuanLyDKHP.App
dotnet run
```
